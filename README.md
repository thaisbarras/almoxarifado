# Turma 3D (Manhã)
## almoxarifado
Sistemas de Almoxarifado Laravel para controle de Produtos e suas movimentações, desenvolvido com os alunos do SENAI

### Objetivos do Sistema
Este sistema gerencia produtos de um almoxarifado, cadastrando os produtos e suas movimentações. Este sistema foi desenvolvido na disciplina de Implantação de Sistemas do Firjan SENAI.
